WADDAH R - النسخة الأولى

المتطلبات:
- Android Studio حديث (يفضل Android Studio Rabbit 1 أو أحدث)
- JDK 17
- Android SDK API 37

طريقة التشغيل:
1. فك الضغط.
2. افتح مجلد NOVA_Social_Android في Android Studio.
3. انتظر Gradle Sync.
4. شغّل التطبيق على المحاكي أو هاتف أندرويد.

هذه النسخة تجريبية وتخزن المنشورات داخل الذاكرة فقط.
الخطوة التالية يمكن أن تكون Firebase لتسجيل الحسابات الحقيقية، الصور، المتابعة، التعليقات والإشعارات.
