# WADDAH R — النسخة الآمنة الأولى

تم تجهيز المشروع ليبدأ الانتقال من MVP إلى تطبيق حقيقي.

### ما تم تأمينه
- Firestore Rules مقيدة حسب UID.
- صلاحيات Admin عبر Custom Claims بدل بريد ثابت داخل التطبيق.
- منع المستخدم العادي من حذف منشورات الآخرين.
- منع تغيير مالك المنشور.
- تقييد الإعجاب إلى زيادة واحدة في عداد المنشور من خلال قواعد Firestore.
- حماية التعليقات بحيث ينشئها صاحب الحساب وتُحذف/تُعدّل من صاحبها.
- حماية الرسائل بحسب المشاركين في المحادثة.
- حماية الإشعارات بحسب صاحب صندوق الإشعارات مع تحقق من المرسل.
- حماية البلاغات بحيث ينشئها المستخدم، بينما الإدارة فقط تقرأها/تراجعها/تحذفها.
- حماية الحظر داخل حساب صاحبه.
- Storage Rules للصور مع حد للحجم ونوع MIME.
- ملفات Firebase CLI للنشر المتكرر للقواعد.

### مهم جدًا
المشروع لا يحتوي على `google-services.json` حقيقي، لأن هذا الملف خاص بمشروع Firebase الخاص بك. ضع ملفك الحقيقي داخل `app/`.

ولا تضع Service Account JSON أو أي مفتاح سري داخل التطبيق.

### الخطوة التالية
بعد ربط Firebase الحقيقي ونشر القواعد، ننتقل إلى تحسين الحسابات والمنشورات والرسائل والإشعارات ثم الاختبارات ونسخة Release/AAB.
